# Governance

## Roles and responsibilities

- **Maintainers** review and merge pull requests, triage issues, cut
  releases, and respond to security reports. Maintainers have write access to
  the repository and admin access to the package registry.
- **Contributors** propose changes through pull requests. Contributors have
  no access to sensitive resources.

## Members with access to sensitive resources

| Member | Role | Access |
|---|---|---|
| Alice Example (@alice-example) | Maintainer, security lead | Repository admin, package registry owner |
| Bob Example (@bob-example) | Maintainer | Repository write, package registry maintainer |

## Granting escalated permissions

A contributor becomes a maintainer only after the existing maintainers review
their contribution history and agree unanimously; the review is recorded in a
public issue before any permission is granted.
