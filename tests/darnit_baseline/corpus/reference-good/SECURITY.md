# Security Policy

## Security contacts

- Alice Example (security lead), security@widget.example
- Bob Example (maintainer), bob@widget.example

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability
reporting ("Report a vulnerability" on the Security tab) or by email to
security@widget.example. Do not open a public issue.

## Coordinated disclosure

We acknowledge a report within 3 business days and send an initial
assessment within 10 business days. We aim to release a fix within 90 days
of the report and coordinate the disclosure date with the reporter. Fixed
vulnerabilities are published as GitHub security advisories.

## Supported versions

Only the latest minor release receives security updates.
